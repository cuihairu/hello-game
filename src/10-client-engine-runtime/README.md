# 8. 客户端架构与引擎体系

这一章讨论客户端为什么会成为独立的系统工程，而不是“把美术和 UI 放进引擎里”。它涵盖引擎、渲染表现、资源管线、网络边界和客户端侧 AI/工具能力。

这一章读完以后，应该能把下面几件事说清楚：

- 能区分引擎能力、项目层架构和工具链建设的职责
- 能判断哪些复杂度必须留在客户端
- 能评估客户端性能、包体和热更压力的来源
