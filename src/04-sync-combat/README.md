# 4. 同步、战斗与实时交互

这一章讨论游戏里最容易引发架构分歧的主题：多端如何共享时间，局内状态如何保持一致，玩家本地为什么需要预测，服务器为什么又必须负责最终裁决。战斗系统的策划规则可以各不相同，但同步问题的本质始终围绕同一组矛盾展开。

对实时交互来说，最大的困难不是“服务器能不能算”，而是本地手感、公平性、反作弊、观战回放和调试成本之间不可能同时最优。任何同步模型都只是把复杂度放在不同位置。
