# 4. 同步、战斗与实时交互

这一章讨论实时游戏中最难、也最容易被误判的一条主线：`时间如何推进，状态如何一致，判定如何公平`。

很多团队会把“同步”理解成一个网络问题，实际上它是时间模型、状态模型、数值模型和协议模型的共同结果。

这章最重要的目标，不是介绍几个同步名词，而是让你建立三个判断：

- 为什么实时系统首先是“时间推进问题”，然后才是网络问题
- 为什么预测、回滚、纠正、回放其实是一整套系统，而不是几个独立技巧
- 为什么很多同步方案失败，不是因为某个算法不够好，而是前置约束没有收紧
