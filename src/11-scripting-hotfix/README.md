# 9. 脚本、热更新与逻辑扩展

这一章关注逻辑扩展能力的建设。脚本层、热更新、配置驱动和宿主运行时不是独立话题，它们共同决定项目后期的迭代速度和事故边界。

这一章读完以后，应该能把下面几件事说清楚：

- 能判断脚本层应该承担什么职责
- 能理解热更新链路为何需要安全与回滚设计
- 能区分配置驱动和脚本驱动的适用边界
