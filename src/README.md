# 游戏开发系统化知识地图

这份知识库面向的是游戏开发中的系统设计、技术选型和长期工程治理，而不是单纯罗列客户端、服务端或运营名词。

它的组织原则很简单：

- 先解释游戏项目真正的问题来源
- 再解释这些问题如何推导到架构和工程方案
- 最后补充附录、专题和横向对照
