# 3. 网络与接入协议

这一章讨论的不是抽象网络原理，而是游戏项目在真实网络环境里必须面对的第一层工程事实：连接如何建立，协议怎样演化，消息怎样分发，弱网时系统如何继续工作。很多后续问题看似出在同步或业务层，根因其实埋在这里。

游戏网络和普通 Web 请求最大的区别，在于它经常需要长期连接、持续状态和对时延极敏感的交互。于是协议设计、可靠性语义、接入层路由和兼容窗口都会和玩法体验直接耦合。
