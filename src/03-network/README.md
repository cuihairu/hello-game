# 3. 网络与接入协议

这一章讨论的不是教科书意义上的网络原理，而是游戏项目在真实线上环境里必须先处理好的那一层工程现实：连接如何建立和回收，消息怎样分层，协议如何演进，接入层承担什么责任，弱网、切网、广播和重连又如何不把主链路拖垮。

游戏网络和普通 Web 请求最大的区别，不是“都走 TCP 或 UDP”，而是它经常同时具备下面几种特征：

- 长连接与长期会话并存
- 高频状态更新和低频控制消息并存
- 强实时链路和强可靠链路并存
- 弱网、切网、后台切前台和重连是常态，不是边缘故障

一旦这些特征进入主线，网络设计就不再只是接入层的实现细节，而会直接塑造同步体系、房间系统、重连体验和可观测性。
