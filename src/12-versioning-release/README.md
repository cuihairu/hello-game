# 10. 版本发布、配置与研发管线

版本问题在游戏里从来不只是“打包上线”。客户端、资源、配置、协议和服务端逻辑经常以不同节奏演进，而玩家、渠道、平台审核和线上活动又会让这些节奏被迫并行存在。于是发布体系本身就成了长期工程能力。

这一章关心的，不是某一次发版如何操作，而是系统如何在频繁变化中保持可控：哪些东西必须同步升级，哪些可以灰度，哪些应该允许旧版本继续共存，出问题时靠什么回退。
