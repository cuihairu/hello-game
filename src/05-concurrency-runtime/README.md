# 5. 执行模型与运行时

这一章关注服务端和引擎内部如何执行逻辑。线程、协程、Actor、任务队列、Tick 驱动和背压机制，最终都在回答同一个问题：如何让逻辑在高负载下仍然可预测。

这一章读完以后，应该能把下面几件事说清楚：

- 知道并发模型和业务模型必须匹配
- 能区分吞吐优化和时序可控之间的不同目标
- 能理解流控和稳定性机制为什么必须提前设计
