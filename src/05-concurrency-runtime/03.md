# Tick 驱动与逻辑执行

很多游戏逻辑天然适合 Tick 驱动，而不是“谁来消息就立即把所有事做完”。

Tick 驱动的价值在于：

- 更新节奏统一
- 逻辑观察点清晰
- 状态推进顺序稳定
- 预算更容易控制

它最重要的工程价值是“预算感”。也就是你知道每一轮主循环该花多少钱，哪些工作超预算了，哪些应该被踢出主链路。

但 Tick 不是万能药。真正要避免的是把所有工作都塞进每一帧：

- 可以延后处理的事情不要进主 Tick
- 可以批处理的事情不要逐帧细碎执行
- 不影响当前体验的工作不要抢主循环预算

一个成熟的运行时，通常会把工作分层：

- 主逻辑 Tick
- 网络收发
- 后台异步
- 定时任务
- 低优先级清理与统计

没有这种分层，Tick 很快就会退化成“所有事都顺手在这做”，然后主链路稳定性被慢慢掏空。
