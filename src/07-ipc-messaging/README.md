# 7. 消息系统与进程间通信

这一章解释进程之间、服务之间为什么需要消息系统，以及消息系统在哪些场景是主链路能力，在哪些场景只是外围集成工具。

这一章读完以后，应该能把下面几件事说清楚：

- 能区分同步调用和消息驱动的边界
- 能理解吞吐、延迟、顺序和幂等为什么难以兼得
- 知道什么链路不该被 MQ 绑死
