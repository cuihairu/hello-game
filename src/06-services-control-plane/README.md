# 6. 服务拆分、分布式与控制平面

这一章讨论服务为什么拆、拆到什么程度，以及拆完之后系统怎样继续被可靠地组织起来。关键不在服务数量，而在状态边界、路由关系和控制平面能力。

这一章读完以后，应该能把下面几件事说清楚：

- 能判断服务拆分应围绕什么边界进行
- 能理解跨服与控制平面的真实成本
- 知道恢复、重连和一致性不能事后补
