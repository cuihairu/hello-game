# 13. 通用游戏服务

这一章整理几乎所有长线项目都会遇到的通用能力：账号、角色、活动、匹配、社交、支付、风控、客服和 GM。它们往往不炫技，但决定项目能否长期运营。

这一章读完以后，应该能把下面几件事说清楚：

- 能理解通用服务为何需要平台化而不是项目内散落实现
- 能看清业务系统和治理系统的接口边界
- 能把运营效率和资产安全放在同一套设计里
