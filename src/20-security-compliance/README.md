# 17. 安全、风控与合规

这一章覆盖安全、反作弊、审计、隐私、版号合规和依赖治理。游戏行业的安全问题既有传统基础设施风险，也有强业务属性的作弊与黑产问题。

这一章读完以后，应该能把下面几件事说清楚：

- 能区分基础安全、业务风控和合规治理
- 能理解安全体系为什么必须和业务流程联动
- 能建立依赖、权限和审计的最低治理标准
