# 游戏数据分类与建模

游戏里的数据至少可以按四种视角来分。

### 按生命周期分

- 瞬时数据：例如局内临时状态、在线状态、匹配状态
- 中期数据：例如赛季进度、活动状态、临时排行
- 长期数据：例如角色成长、资产、交易记录、社交关系

### 按权威性分

- 强权威数据：例如货币、订单、发货结果、关键结算
- 可重建数据：例如部分缓存、派生统计、中间索引

### 按访问模式分

- 高频读写
- 高频读低频写
- 低频读高价值写
- 批处理和分析型访问

### 按业务语义分

- 角色数据
- 局内战斗数据
- 世界状态数据
- 经济与交易数据
- 社交与关系数据
- 日志与分析数据

只有把这些维度叠起来看，才知道哪些数据能放在一起，哪些必须分层处理。
