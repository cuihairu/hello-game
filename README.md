# 游戏后端知识体系

一个系统化的游戏服务器开发知识库，涵盖从入门到实战的完整技术体系。

## 定位

这不是一个可运行的游戏工程，而是一套**游戏后端开发的知识地图**。适合：
- 想入行游戏后端的开发者
- 想系统梳理知识的游戏后端工程师
- 想了解游戏技术的产品/策划/测试

## 目录结构

站点由**教程**与**知识库**两部分组成，二者主线同题对应：教程是 18 讲的实战路线，知识库是逐章展开的参考体系。
