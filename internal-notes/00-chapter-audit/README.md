# 逐章审查

这份审查只看当前仓库里的章节状态，不假设未来内容。结论很直接：当前 23 章几乎都是提纲页，章节名大体成立，但正文基本还没开始写。

审查维度：

- 定位是否清楚
- 是否与其他章节明显重叠
- 是否值得保留为一级章节
- 当前重写优先级

优先级定义：

- `P0`：必须先定边界，否则别的章会反复打架
- `P1`：一级主线，适合尽快开始写正文
- `P2`：可以后写
- `P3`：不建议继续保留为一级章节
