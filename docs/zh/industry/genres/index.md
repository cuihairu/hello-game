# 游戏类型专题

## Category

industry / genres 子树总览。覆盖：房间制与轻量在线（01）、强实时对战（02）、持续在线世界（03）、长周期成长与经营（04）、平台与生态型（05）、使用说明（06）。

## Definition

这一组附录按常见游戏类型对照技术问题，不试图给品类下定义，重点记录不同产品通常会把技术复杂度集中在哪些地方。

按类型看问题有两个好处。第一，它更接近团队日常沟通，便于和策划、制作人、发行一起对齐。第二，它能呈现同样叫“游戏服务端”的项目之间，难点为何会有明显差异。

但品类不是架构结论。真正决定系统形态的，仍然是状态共享方式、时间推进方式、内容生产方式、运营节奏和商业约束。两个都叫 MMO 的项目，技术形态也可能天差地别；一个看起来像休闲游戏的产品，也可能因为强社交和高频活动而变得非常复杂。

这组记录涉及的核心问题：

- 不同游戏类型对应的主要技术压力
- 同一品类内部架构分化的原因
- 品类标签作为沟通索引的适用边界
