# 玩法分类：完整品类光谱

## Category

industry / genres 子树。节点定位：从公开来源汇总的玩法分类合集——市场所用的完整品类光谱，包含子类拆分与跨品类混合形态。

## Definition

电子游戏品类是一种基于游戏“怎么玩”的非正式分类，与视觉或叙事元素无关。同一品类标签不随题材改变：只要具备第一人称镜头和远程武器玩法，第一人称射击无论套科幻、西部、奇幻还是军事外皮，都仍是第一人称射击。品类的解读带有主观性，且常常相互重叠；一款游戏可以同时归入多个品类，浏览器游戏和手机游戏尤其如此。

本页把市场常见的品类光谱收进一个视图。它是一份**分类学，不是架构答案**——按照类型子树的规则（06），品类标签只作为沟通索引和问题索引，永远不能替代设计。架构侧的问题模型见 [models/01](/zh/industry/models/01)（六问分型）。

## Classification Schemes

品类可以沿几条相互独立的轴来分类。只有玩法是真正的品类轴，其余都是替代性的归类方案：

| 轴 | 含义 | 例子 |
| --- | --- | --- |
| 玩法（真正品类） | 游戏怎么玩 | 射击、平台跳跃、RPG、策略 |
| 平台 | 跑在什么硬件上 | 手机、主机、PC、浏览器 |
| 模式 | 单人还是多人 | SP、MP、合作、PvP、PvE、MMO |
| 叙事 | 题材/故事风格（非品类） | 科幻、奇幻、恐怖 |
| 生产 | 预算/来源 | 3A、独立、同人、粉丝游戏 |
| 设计 | 结构性设计标签 | 休闲、超休闲、抽卡、开放世界 |

玩法轴是类型子树唯一视作主轴的维度。其余只是项目定界时的背景信息，不是品类决策。

## The Genre Spectrum

下面的光谱沿用常见的品类家族。每个家族列出主要子类；跨品类混合形态在市场常见处标注。

### 动作

最宽的家族，以身体挑战为核心——反应、时机和空间协调。

| 子类 | 核心特征 |
| --- | --- |
| 街机 | 规则简单，追求分数，单局时间短 |
| 平台跳跃 | 平台间跳跃；精密移动 |
| 格斗 | 一对一近战，连招，帧数据 |
| 清版动作 | 横版近战对抗成群敌人 |
| 砍杀 | 近战战斗 + 装备成长 |
| 射击 | 远程武器，以瞄准为核心 |
| ─ 第一人称（FPS） | 镜头模拟主角双眼 |
| ─ 第三人称（TPS） | 镜头在角色身后 |
| ─ 英雄射击 | 团队制，角色技能 |
| ─ 竞技场射击 | 高速移动，竞技场对抗 |
| ─ 战术射击 | 节奏慢，重站位，一击致命 |
| ─ 撤离射击 | 搜刮并撤离，PvPvE |
| ─ 弹幕射击 | 躲避弹幕 |
| ─ 弹幕地狱 | 高密度弹幕，极小判定 |
| ─ 轨道射击 | 镜头固定轨道，射击走廊 |
| ─ 双摇杆 | 双模拟摇杆，俯视角 |
| ─ 光枪 | 用外设瞄准 |
| ─ 刷宝射击 | 射击 + 装备稀有度 |
| 生存 | 资源稀缺，应对威胁 |
| ─ 大逃杀 | 最后一人存活，缩圈 |

| 子类 | 核心特征 |

| 行走模拟器 | 氛围探索，交互极简 |

## 跨品类与混合形态的现实

绝大多数真实产品都是混合体。对架构有意义的市场常见混合体：

- **Roguelike 卡组构筑**（《杀戮尖塔》）：卡组构筑 + 跑局结构——2010 年代商业影响力最大的混合形态之一。
- **刷宝射击**（《命运》《无主之地》）：射击 + 装备稀有度。
- **生存建造**（《我的世界》《英灵神殿》）：采集 + 建造 + 共享世界。
- **抽卡 RPG**：RPG + 抽卡商业化（见 08）。
- **大逃杀**：射击 + 最后一人存活的生存对抗。

[genre-coverage](/zh/system/genre-coverage.md) 中的品类对照表把 21 个市场常见品类映射到各自最先要求的特性组件——那是这份分类学的架构侧配套。

## Problem

没有纪律的分类学会变成跳过分析的借口。两个坑最常见：

- **品类 = 架构答案。**“MMO”或“SLG”的标签不是设计。系统形态由状态共享、时间推进、内容生产、运营节奏和商业约束决定——两个都叫 MMO 的项目在技术上可能相去万里。
- **题材与品类混淆。**题材（修仙、武侠、三国、二次元）只是换皮，不改变构件。只有玩法和商业形态会改变服务端组件需求。
