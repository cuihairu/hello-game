# 成瘾机制：游戏设计中的行为工程

## Category

industry / genres 子树。节点定位：让某些游戏循环“好玩到出问题”的行为机制——留存与商业化背后的心理学与神经经济学，以及伦理边界所在。

## Definition

游戏成瘾不是单一机制，而是一组强化结构的集合。研究最多、商业上最核心的是：

- **变比率强化**——让行为难以消退的奖励时间表。
- **奖赏预测误差（多巴胺）**——驱动“想要”（渴求）而非“喜欢”（享受）的神经信号。
- **损失厌恶与沉没成本**——让玩家在乐趣消退后仍不肯离开的偏差。
- **FOMO 与限时紧迫感**——迫使近期行动的稀缺信号。
- **习惯迁移**——重复累积后，从目标导向行为转向自动行为。

这些机制本身并不“邪恶”。让一个精心设计的游戏循环引人入胜，用的正是同一批原理。对游戏工作室来说，真正的问题是边界在哪：让玩家进入一个奖励技巧与精通的循环，与刻意设计一个利用不确定性来最大化付费的循环，是两回事。

## The Reinforcement Schedules

斯金纳的操作性条件反射研究定义了若干奖励时间表。这里最关键的一个：

| 时间表 | 定义 | 行为效应 |
| --- | --- | --- |
| 连续强化（CRF） | 每次反应都奖励 | 学得快，消退也快 |
| 固定比率（FR） | 每 N 次反应奖励一次 | 可预测的爆发，奖励后有停顿 |
| 变比率（VR） | 随机次数后奖励 | **最易成瘾：稳定的高反应率，极难消退** |
| 固定时距（FI） | 固定时间后奖励 | 扇形反应模式 |
| 变时距（VI） | 随机时间后奖励 | 稳定、中等反应率 |

变比率时间表就是老虎机、彩票和开箱背后的机制。玩家无法预测奖励何时出现，因此反应率持续走高，即使奖励停止兑现，行为依然难以消退。

## The Neuroscience: Dopamine and Reward Prediction Error

流行文化把多巴胺叫做“快乐分子”。神经经济学表明它更精确地关乎*预测*——**奖赏预测误差（RPE）**，即预期奖励与实际奖励之差：

- **正预测误差**（得到的比预期多）：多巴胺神经元强烈放电，发出“再做一次”的信号。
- **负预测误差**（得到的比预期少）：多巴胺回落。

关键的洞见：**在不确定性下，多巴胺在*线索*出现时就放电——早于奖励揭晓。**期待本身就是奖赏。这就是为什么开箱动画又长又炫——它们在工程化地制造*想要*（渴求）而非*喜欢*（满足）的状态。“想要”与“喜欢”的区分是核心：成瘾者对奖赏的渴望超过了对它的享受。

## From Goal-Directed to Habitual Behavior

反复强化会让控制权在大脑内转移：

- **最初的行为是目标导向的**，由伏隔核（腹侧纹状体）驱动——你是有意识地想要那个物品。
- **重复足够多次之后**，尤其在变比率时间表下，控制权转移到**背侧纹状体（基底神经节）**——自动化、程序化，脱离意识觉察。

一旦转移，线索（一条推送通知、一个闪亮的按钮）就会触发自动运动程序，无需刻意决策。这是强迫行为的神经特征，也是“我就再来一次”能压过一切理性停止决定的原因。

## Loss Aversion and Sunk Cost

- **损失厌恶**：损失的痛苦在心理上约是等量收益快乐的两倍。
- **沉没成本谬误**：一旦投入了时间或金钱，停止就像浪费。

设计者通过每日登录奖励、战斗通行证和限时活动来运用这些偏差。今天不登录，你就“失去”了奖励；大脑把错过读作痛苦的损失，即使不想玩也会促使你登录。战斗通行证预先投入一笔沉没成本（“我已经付过钱，应该肝完”），让游玩得以延续。

## Loot Boxes as the Paradigm Case

开箱是研究最多的现代实例，因为它们在结构上与赌博相似：

- 运行在**变比率强化时间表**上（与老虎机相同）。
- 最诱人的奖励刻意做成**最稀有**（常常 < 1% 概率）。
- 奖励揭示时伴随**视听刺激**。
- **限时优惠**制造紧迫感。

实证结论（Drummond & Sauer 2018；Brooks & Clark 2019；Larche & Dixon 2020——见参考资料）：

- 越稀有的开箱奖励，唤起（皮肤电导）越大，奖赏反应越大，再开一箱的冲动越强。
- 越稀有的箱子，强化后停顿越长——这是与赌博共有的奖赏反应性指标。
- 预期性唤起在揭晓*之前*就已上升——线索驱动的多巴胺反应。
- 开箱消费与**问题赌博症状**相关（在澳大利亚、新西兰和美国样本中均得到重复验证）。
- 开箱满足赌博的心理学标准，在某些司法辖区甚至满足**法律标准**。

这就是开箱处在监管争论中心的原因——见治理一节。

## The Ethical Line for a Game Studio

以上机制是工具。伦理问题在于用它们做什么：

| 意图 | 伦理 | 剥削性 |
| --- | --- | --- |
| 奖励技巧与精通 | ✔ | — |
| 让成长有“挣来”的感觉 | ✔ | — |
| 制造正当的期待 | ✔ | — |
| 设计不确定性以最大化付费 | — | ✔ |
| 猎取无法停下的玩家 | — | ✔ |
| 隐藏或虚报概率 | — | ✔ |

负责任的工作室采用的、且在部分市场被强制要求的实用护栏：

- **公示概率**——公布掉率（中国自 2017 年起强制，其他市场日益跟进）。
- **保底机制**——N 抽后必得稀有奖励；把变比率陷阱变成可预测的下限。
- **消费限额与年龄门槛**——每日消费上限，未成年人家长控制。
- **竞技场景避免 pay-to-win**——仅外观付费可避免“付费换优势”的螺旋。
- **单局时长设计**——自然的停止点，而不是无限肝。

## Governance and Regulation Snapshot

- **中国**（2017 年颁布，2018 年生效）：游戏必须**公示**所有随机奖励物品的**概率**，且厂商须记录并在被要求时提供。未成年人被禁止部分开箱购买路径。
- **比利时**（2018）：赌博委员会认定涉及付费与随机性的开箱构成**赌博**；多款游戏被要求移除。
- **荷兰**（2018）：依据赌博法认定开箱为赌博；游戏管理局要求含可交易道具的游戏作出修改。
- **英国**（2019–）：DCMS 调查呼吁**禁止未成年人购买开箱**，并配套年龄验证与家长控制；2020 年《适龄设计守则》对面向儿童的服务增设义务。
- **欧盟**（2023–）：欧洲议会通过决议，呼吁对开箱采取协调一致的路径，并建立**赌博式机制的共同定义**。

监管不均衡且仍在演变。规律是：针对未成年人的随机性商业化，越来越多地被当作赌博产品对待。对工作室而言，安全的工程姿态是默认概率公示 + 保底 + 消费上限 + 年龄门槛。
