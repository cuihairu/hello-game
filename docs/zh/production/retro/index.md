# 选型、实践、复盘与清单

## Category

production / retro 子树总览。覆盖：选型方法（01）、架构模式对照（02）、评审清单（03）、失败案例分析（04）、个人自检（05）。

## Definition

这一章把前面的内容压回到实践层，回答“怎么选”“怎么复盘”“怎么避免重复犯错”。它不是列最佳实践，而是帮助团队建立决策和纠偏机制。

这组记录涉及的核心问题：

- 前文判断如何沉淀为选型与复盘清单
- 常见失败模式及其触发条件
- 方案评审中如何识别未经验证的假设

## Related

关系链：选型方法（01）→ 模式对照（02）→ 评审清单（03）→ 案例分析（04）→ 个人自检（05）。上游：client/engines 子树（选型的商业、语言、团队三面）；下游：server 树（服务端模式展开）。
