# 历史线首批节点清单（八轨 · 76 条）

> 这是 `docs/history/index.md` 八轨时间线的首批节点清单，与运行时数据 `docs/.vitepress/theme/data/timeline.mjs` 一一对应（测试断言每个条目标题都能在本页找到）。每条三要素：**硬件背景**（出现时的硬件/环境约束）、**解决了什么**、**弊端**——缺一不算完成。年份以公开资料通行说法为准，资料不一标「约」。互链关系（受 X 影响 / 催生 Y）在页面卡片上双向成对展示，登记形式见文末。

## ① 游戏发展（10 条）

| 年 | 条目 | 硬件背景 | 解决了什么 | 弊端 |
|---|---|---|---|---|
| 约1962 | Spacewar!（PDP-1） | 小型机加示波器显示，内存 16KB 级，图形靠手写代码直写显示设备 | 证明实时交互图形程序可以运行、可以被复制传播，游戏从纸面变成可运行的程序 | 只存在于实验室与大学，无商用形态；依赖特定机型，几乎无法分发 |
| 1972 | Pong 街机 | TTL 分立元件专用街机板，无通用 CPU，画面只有黑白方块与线条 | 第一个大规模商业成功的电子游戏，证明电子游戏是一门生意 | 功能焊死在电路上，游戏与硬件一体；克隆泛滥、无内容更新概念 |
| 1978 | Space Invaders（太空侵略者） | Intel 8080 街机板、单色 CRT、内存以 KB 计 | 确立高分榜与难度递增的重复可玩性机制，街机黄金时代的商业引擎 | 小内存硬编码渲染；每帧 sprite 预算固定，敌军数量减少时变快被当成 bug 传世 |
| 1983 | 北美雅达利大崩溃 | 2600 十年老架构、卡带 4KB 主流，开发无质量门槛 | （事件）质控失守倒逼行业重建：1985 年起任天堂质控公约成为北美市场复苏起点 | 行业塌方，北美主机市场冰封约两年，大量公司倒闭 |
| 1985 | 超级马里奥兄弟（FC） | 6502@1.79MHz、2KB RAM、54 色，卡带容量决定内容上限 | 确立横版卷轴关卡设计方法论：教学关、卷轴节奏、隐藏要素的组合范式 | 卡带容量限内容量，无电池存档，续关成为唯一进度保护 |
| 1996 | Quake | 486/Pentium 加 Voodoo 加速卡，网络仍在拨号与早期宽带 | 实时全 3D 与网络对战成为产品现实，客户端/服务端分工被产品验证 | 高配门槛，软渲染几乎不可玩；对战依赖局域网与专用服务器普及 |
| 2004 | 魔兽世界 | PC 普及与宽带入户，家用网络可支撑持续在线 | 百万级订阅 MMO 与副本实例化范式，长线运营成为主流商业模式 | 点卡时间投入制带来健康争议，内容消耗速度倒逼产能军备 |
| 约2009 | Minecraft（测试版） | Java 跨平台，低配 PC 即可运行，网页分发绕开传统渠道 | 沙盒 UGC 玩法范式，独立团队做出现象级产品的样本 | Java 性能天花板，优化长期欠账；模组生态兼容性问题多 |
| 2016 | Pokémon GO | 智能手机 SoC、GPS 与 4G 网络普及，陀螺仪与摄像头成标配 | LBS + AR 玩法大众化，位置服务支撑全球规模并发 | 安全事故与公共场所秩序压力，定位作弊与外挂 |
| 2020 | 原神 | 手机 GPU 已达上世代主机水平，跨端同一份资产可分发 | 跨端高品质开放世界加长线版本运营的全球样本 | 研发成本与持续更新产能压力，抽卡付费争议 |

## ② 硬件（10 条）

| 年 | 条目 | 硬件背景 | 解决了什么 | 弊端 |
|---|---|---|---|---|
| 约1971 | Intel 4004 | 分立逻辑与 SSI/MSI 芯片时代，一块板一个功能 | 首款商用微处理器，把 CPU 变成可采购的标准件，通用计算起点 | 4 位数据宽度，需大量外围芯片拼系统，单价高、生态未形成 |
| 1981 | IBM PC 5150 | 8088@4.77MHz、64KB 内存，操作系统靠软盘 | x86 加开放架构确立 PC 标准，兼容机生态爆发 | 约 1565 美元起的高价与笨重体积，DOS 命令行门槛 |
| 1985 | Amiga 1000 | 自定义图形与音频芯片（blitter、Paula），多媒体能力远超同代 PC | 消费级多媒体能力：硬件合成音、逐帧动画与多任务 | 平台封闭、价格高，被开放的 PC 兼容机挤出主流 |
| 1989 | Sound Blaster | PC 音频此前只有蜂鸣器，1987 AdLib FM 音乐先行 | 把音效与音乐采样带进 PC，确立 PC 游戏音频事实标准 | IRQ/DMA 手工配置的兼容地狱，克隆卡差异 |
| 1996 | 3dfx Voodoo | CPU 软渲染跑不动真 3D，纹理与帧率全靠主频硬扛 | 消费级 3D 加速：光栅化与纹理过滤进显卡，3D 游戏成为大众品类 | 需另配 2D 显示卡，专有 Glide API 形成锁定，后续被 DirectX 生态吞掉 |
| 1999 | GeForce 256 | 几何变换与光照全在 CPU，显卡只管画三角形 | 硬件 T&L，「GPU」一词起点，几何管线卸载到显卡 | 驱动不稳、售价高，过渡期需主副双卡 |
| 2001 | GeForce 3 与可编程着色器 | 固定功能图形管线到顶，特效只能靠厂商预置寄存器组合 | 顶点/像素着色器可编程，材质与特效从预置变成写代码 | Shader 版本碎片化，跨厂商移植成本与编程门槛抬升 |
| 约2005 | 多核普及（Xbox 360 三核 / Core 2 Duo） | 单核主频撞墙（NetBurst 路线失败），功耗与散热到顶 | 用并行换总性能，游戏与服务端都转向多线程 | 并行编程复杂度陡增，既有代码重写，收益难榨 |
| 2007 | iPhone | 触屏 SoC 随身计算，移动网络从 WAP 走向数据流量 | 移动游戏平台化底座，App Store 分发重塑渠道 | 功耗散热限制性能，生态封闭与 30% 抽成 |
| 2018 | RTX 2080（RT 与 Tensor 核心） | 光栅化管线高度成熟，AI 推理算力开始进消费级显卡 | 实时光线追踪与超分（DLSS）硬件化，渲染管线多出新一级 | 价高功耗大，RT 游戏渗透慢，生态与开发门槛同步抬升 |

## ③ 前端技术（10 条）

| 年 | 条目 | 硬件背景 | 解决了什么 | 弊端 |
|---|---|---|---|---|
| 约1991 | WWW 与 HTML 公开 | NeXT/Unix 工作站与拨号网络，文档靠 FTP 与邮件传播 | 超文本跨机构分发，链接把文档连成网 | 纯文档，无交互无图形，浏览器最初只是阅读器 |
| 1993 | Mosaic 浏览器 | 486 工作站与家用机，图形界面成为 PC 标配 | 图形化浏览加内嵌图片，Web 走向大众 | 慢，渲染兼容差，标准跟不上实现 |
| 1995 | JavaScript | 浏览器仍按文档阅读器设计，表单校验靠整页刷新 | 页面交互逻辑有了语言，十天原型撑起前端生态 | 语言设计仓促的历史坑（this、类型转换、回调地狱） |
| 约1999 | XMLHttpRequest 与 AJAX | 带宽窄，整页刷新昂贵，富交互应用只能靠插件 | 局部刷新成为可能，富应用路线打开 | 无标准实现差异，回调地狱，可访问性差 |
| 2006 | jQuery | 浏览器大战 IE6 碎片化，DOM 与事件模型各家一套 | 一行选择器抹平 DOM 与兼容差异，操作门槛大降 | 选择器滥用与 DOM 操作性能债，抽象掩盖原生能力 |
| 2008 | Chrome 与 V8 | 硬件已够快，JS 引擎仍是解释执行，网页应用卡顿 | JIT 让 JS 进入近原生性能时代，Node.js 生态随之起势 | 单线程模型遗留至今，重任务仍要 Worker 绕行 |
| 约2011 | Three.js 与 WebGL 1.0 | GPU 可编程着色器（2001）已成熟八年，浏览器却无图形接口 | 浏览器 3D 开发门槛大降，Web 从文档走向应用与游戏 | 移动端兼容参差，调试工具原始，性能上限受浏览器制约 |
| 2013 | React 开源 | 多核桌面与大内存浏览器，前端应用复杂度爆炸 | 组件化加虚拟 DOM，声明式 UI 范式与生态工程化 | 生态复杂、版本迁移成本，状态管理方案分裂 |
| 2017 | WebAssembly MVP | CPU 与浏览器引擎成熟，靠近原生的执行环境可用 | C/C++/Rust 近原生进浏览器，游戏与重计算有了 Web 落点 | 体积、GC 互操作与调试断点，DOM 交互仍绕行 |
| 2023 | WebGPU 在 Chrome 稳定 | 现代图形 API（Vulkan/Metal）世代，浏览器安全沙箱收紧 | 现代 GPU API 统一进 Web，计算与渲染同级暴露 | 规范仍在演进，跨浏览器支持不齐，学习成本高于 WebGL |

## ④ 后端技术（9 条）

| 年 | 条目 | 硬件背景 | 解决了什么 | 弊端 |
|---|---|---|---|---|
| 1970 | 关系模型与 SQL | 大型机磁盘存储昂贵，数据组织靠层次与网状模型 | 结构化数据的声明式查询与一致性保障，数据独立于程序 | 非结构化与层级数据不适配，规模扩展需分库分表 |
| 约1995 | LAMP 组合 | PC 服务器远比小型机便宜，开源组件开始可组合 | Web 服务低成本快速搭建，中小团队上线门槛消失 | PHP 类型松散与性能天花板，进程模型限制并发 |
| 约2003 | memcached | 内存价格持续下降，多机共享内存缓存成为可能 | 分布式对象缓存的标准件，挡在数据库前面的通用加速层 | 无持久化、一致性弱、淘汰粗暴，缓存与数据一致性要自己管 |
| 约2004 | GFS 与 MapReduce 论文 | 商用 PC 集群的可靠性与容量可与小型机掰手腕 | 百节点级存算的工程范式：冗余换可靠，批处理换吞吐 | 论文到可用生态有数年落差（Hadoop 2006 才成形） |
| 2009 | Redis 开源 | 内存价格与多核服务器普及，缓存需求细分到数据结构 | 内存数据结构服务：排行榜用 ZSet，锁与队列一套结构打天下 | 内存成本，持久化与主从模型在演进中踩坑（RDB/AOF 选择） |
| 2009 | Go 开源 | 多核时代到来，C/C++ 写并发服务的复杂度到顶 | 并发友好的语言：goroutine 让高并发网关与基础设施好写好部署 | 泛型迟至 1.18，运行时 GC 停顿，错误处理啰嗦 |
| 2011 | Kafka 开源 | 磁盘顺序写便宜、SSD 与集群网络普及 | 高吞吐持久事件流，回放语义把解耦与追溯做成基础设施 | 运维复杂（早期 ZooKeeper 依赖），分区与顺序语义有边界 |
| 约2013 | Docker 与 Kubernetes | 云主机已成默认算力形态，交付物还停在虚拟机镜像 | 环境一致交付与容器编排，发布从换机器变成换镜像 | 学习成本，网络与存储复杂度外移，安全面变大 |
| 2015 | gRPC 开源 | 多语言微服务铺开，JSON+REST 的契约松散开始疼 | 强契约 RPC 与多路流式通信，接口定义变成可编译资产 | 人读性差（HTTP/2 二进制），排障与抓包门槛抬升 |

## ⑤ 知名引擎（9 条）

| 年 | 条目 | 硬件背景 | 解决了什么 | 弊端 |
|---|---|---|---|---|

| 1996 | Quake 引擎 | Pentium 时代，3D 加速卡前夜 | 真 3D 与客户端/服务端架构分离，实时网游的默认分工定型 | 配置要求高，内容制作门槛高，授权与二次开发门槛更高 |
| 1998 | Unreal Engine 1 | 1997 年的显卡与 CPU 已能跑复杂室内场景 | 引擎授权成为独立商业模式，不靠卖游戏也能靠引擎赚钱 | 授权费高，内容管线重，小团队够不着 |
| 约2001 | RenderWare（GTA III 采用） | PS2 世代多平台并存，每平台一套底层要重写 | 一套中间件跨平台（PS/Xbox/PC），开放世界大作得以量产 | 2004 年被 EA 收购后路线式微，单一供应商风险 |
| 2004 | Source 与 CryEngine | 高清世代 GPU 与 DirectX 9，可编程管线刚铺开 | 光照、物理与工具链的 2000s 标杆，编辑器工作流成型 | 授权与工具链封闭，跨代升级成本高 |
| 2005 | Unity 1.0 | 消费级开发机性能足够，跨端发布开始有统一中间层 | 引擎民主化：小团队可做 3D 与跨端，移动浪潮的隐形地基 | 大作级内容上限，早期移动端性能与重度工程支持弱 |
| 2010 | cocos2d-x | 智能手机 2D 游戏爆发，开发者要 C++ 跨端方案 | 跨端 2D 标准件，中国移动游戏的主力工具链 | 3D 能力弱，工具链简陋，生态向 Cocos Creator 收拢 |
| 2014 | UE4 转免费与 Godot 开源 | 独立开发潮与 Steam 分发成熟，预付授权成为门槛 | 免预付加分成的门槛下探，开源引擎给出第三选择 | 商业分成绑定，开源生态支持参差，迁移成本仍在 |
| 约2020 | UE5（Nanite 与 Lumen） | RTX 世代显卡与大容量 SSD 进入主流机型 | 电影级资产直接进实时渲染，几何与光照成本模型重定 | 硬件门槛高，老项目迁移重，中小团队驾驭成本高 |

| 1998 | 3D 空间交互（时之笛 Z 锁定） | 3D 加速卡与主机已普及，镜头与操作仍是未解题 | 解决 3D 下打谁、怎么打的相机难题，动作 3D 的交互基准 | 晕动与镜头穿帮问题未根治，锁定在多敌人场景受限 |
| 2004 | MMO 时间投入制 | 宽带普及，账号与角色可长期在线 | 社交绑定与长线进度留存，订阅制商业模型成型 | 时间成本与上班感争议，强迫日常透支乐趣 |
| 约2006 | F2P 道具收费 | 支付通道与网络普及，游戏分发零门槛 | 零门槛进入加道具/数值付费，商业模式与获客逻辑改写 | 数值逼氪与游戏性失衡的批评，付费深度难调平 |
| 2009 | MOBA 降门槛（英雄联盟） | PC 与网吧普及，低配机型是主流玩家配置 | 把 Dota 玩法大众化，电竞体系的底座产品 | 单局体验强绑定，外挂与演员治理是长期战 |
| 约2017 | 大逃杀与赛季通行证 | 大地图 100 人同步在公网可行，网络与 CPU 都到位 | 每局不确定性带来观赛性，战令把活跃与付费绑进赛季 | 平衡调整频繁，外挂压力大，内容管线被赛季节奏拖着跑 |
| 2017 | 系统涌现（旷野之息） | 主机 CPU 足够跑交互系统实时模拟 | 元素交互替代脚本演出，开放世界的化学引擎设计法 | 系统组合难调平，性能吃紧，bug 面变大 |

## 互链登记口径

互链在数据文件里以一行登记一条因果：`[源 key, 目标 key, 源侧注记, 目标侧注记]`，装配时自动生成源侧 `out`（`→ 催生/代表作…`）与目标侧 `in`（`← 受…影响`）两条徽标，保证双向成对。首批铺设 29 条，覆盖跨轨因果 14 组以上，示例：

```text
hw-2001-shader → 催生 fe-2011-webgl / en-2004-source / ar-2001-realism
hw-1996-voodoo → 催生 ar-1996-lowpoly / en-1996-quake-engine
hw-2007-iphone → 催生 ga-2016-pogo / gp-2006-f2p
ga-1978-invaders → 催生 gp-1978-highscore
co-1981-nintendo ↔ 代表作 ga-1985-smb → 确立 gp-1985-platform
hw-2005-multicore → 催生 be-2009-go
en-2020-ue5 → 抬高 ar-2020-fidelity（受 hw-2018-rtx 支撑）
```
