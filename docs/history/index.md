# 游戏发展历史线

> 技术选型不是凭空来的：今天游戏服务端里的每一样东西——分片、状态同步、匹配服务、排行榜、容量扩缩——都是某个年代某款具体产品在具体约束下逼出来的答案。这条时间轴沿**三条线**回看 1970s 以来的游戏史：
>
> - **技术线**：网络、同步与服务器架构的演进（本站主场，含后端向节点）；
> - **引擎线**：从游戏与代码一体，到引擎授权商业模式的成型与今天格局；
> - **名作线**：每个年代绕不开的作品，标注平台与它带来的新东西。
>
> 年份以公开资料中较通行的说法为准；细节存有争议或资料不一的，标注「存疑」。

总览：[1970s](#s-1970s) · [1980s](#s-1980s) · [1990s](#s-1990s) · [2000s](#s-2000s) · [2010s](#s-2010s) · [2020s](#s-2020s)

## 1970s · 多人在场的起点 {#s-1970s}

### 技术线

| 年份 | 事件与意义 |
| --- | --- |
| 1969 | ARPANET 首批节点上线，分组交换网络进入实用——一切联网游戏的物理前提 |
| 1978 | **MUD1**（埃塞克斯大学）在 DEC PDP-10 上运行：多人同时进入一个持久虚拟世界，网游的全部原型问题（在线状态、房间、持久化）在这里首次出现 |

### 引擎线

| 年份 | 事件与意义 |
| --- | --- |
| 1970s | 游戏与硬件一体：街机是专门电路板，主机游戏直接对地址总线编程，「引擎」概念尚未存在 |

### 名作线

| 年份 | 作品 · 平台 | 它带来了什么 |
| --- | --- | --- |
| 1972 | Pong · 街机（Atari） | 证明电子游戏可以是生意，街机产业起步 |
| 1977 | Atari 2600 · 主机 | 卡带可换游戏的家庭主机平台，第三方发行商生态雏形 |
| 1978 | Space Invaders · 街机（Taito） | 全球现象级产品；街机高分榜成为最早的「玩家数据竞争」形态 |

## 1980s · 榜单、存档与虚拟世界雏形 {#s-1980s}

### 技术线

| 年份 | 事件与意义 |
| --- | --- |
| 1983 | TCP/IP 成为 ARPANET 标准协议，网络互联有了统一语言 |
| 1985 | **Habitat**（Lucasfilm，CompuServe 网络上的图形化虚拟世界）：面向消费级网络的多人图形世界先声，服务端承载世界状态的做法由此铺开 |
| 1980s | 街机与早期主机时代的「排行榜」「存档」仍是本地形态——高分榜在机台内存里，存档在卡带电池里；玩家数据的服务端化要等网络普及 |

### 引擎线

| 年份 | 事件与意义 |
| --- | --- |
| 1980s | 游戏团队为每款作品重写底层代码；家用机平台的技术约束（内存、卡带容量）直接决定程序写法——客户端约束反向决定技术形态的最早例证 |

### 名作线

| 年份 | 作品 · 平台 | 它带来了什么 |
| --- | --- | --- |
| 1980 | Pac-Man · 街机（Namco） | 电子游戏的大众文化符号 |
| 1980 | Rogue · 终端（大学 Unix） | Procedural 生成 + 永久死亡，Roguelike 品类源头 |
| 1985 | Super Mario Bros. · FC（Nintendo） | 平台跳跃的动作范式与关卡设计方法论 |
| 1986 | 塞尔达传说 · FC（Nintendo） | 电池存档：玩家进度可保存，「世界状态持久化」走进家用场景 |
| 1989 | Tetris · Game Boy（Nintendo / Elorg 版权链） | 掌机 + 俄罗斯方块：游戏第一次随身携带 |

## 1990s · 网络同步与持久世界 {#s-1990s}

### 技术线

| 年份 | 事件与意义 |
| --- | --- |
| 1993 | Doom 支持调制解调器与局域网对战：多人实时对战进入大众视野；开放的 WAD 文件格式带出模组生态——UGC 的早期形态 |
| 1996 | **QuakeWorld**（id Software）为延迟补偿重写网络代码：客户端预测、插值与时间戳同步成为 FPS 网络同步的教科书答案（见[第 04 讲](/24-game-types-architecture/04-network)） |
| 1996 | Battle.net 随 Diablo 上线：玩家账号、大厅与联机对战平台化——在线服务与匹配体系的商业起点 |
| 1997 | **Ultima Online**（Origin）：商用持久世界走上规模，「分片（shard）」成为 MMO 服务器架构的基础词——按世界副本拆分在线容量（见[按问题域归纳各类游戏](/09-problem-domain/)） |
| 1999 | EverQuest 交付 3D 化大型持久世界，3D MMO 的服务器负载（大地图无缝移动、AoI）成为新的工程课题 |

### 引擎线

| 年份 | 事件与意义 |
| --- | --- |
| 1992–1993 | id Software 的 Wolfenstein 3D 与 Doom：游戏底层技术第一次以「引擎」的面目被复用与授权 |
| 1996 | Quake 引擎支持硬件加速与客户端/服务端明确分离——这一架构分工从此成为实时网游的默认形态 |
| 1998 | **Unreal** 与 Unreal Engine 1（Epic）：引擎授权作为独立商业模式正式成立 |
| 1999 | Quake III Arena（id Tech 3）：物理与判定进一步收拢到服务端权威，为竞技公平与反作弊立下参照 |

### 名作线

| 年份 | 作品 · 平台 | 它带来了什么 |
| --- | --- | --- |
| 1991 | 文明 · PC（MicroProse） | 回合制策略的深度与「再来一回合」 |
| 1994 | 魔兽争霸 · PC（Blizzard） | RTS 品类的竞争范式， Blizzard 在线社区的起点 |
| 1996 | 宝可梦 红/绿 · Game Boy（Game Freak） | 收集+交换：联机交换把「社交资产」做进了掌机 |
| 1997 | 最终幻想 VII · PlayStation（Square） | RPG 的电影化叙事，主机 RPG 全球化的转折 |
| 1997 | Ultima Online · PC | 第一个大规模商用虚拟社会：经济系统、玩家治理、世界事件 |
| 1998 | 半衰期 · PC（Valve） | 叙事与第一人称射击的融合；Mod 社区孕育出 CS |
| 1998 | 星际争霸 · PC（Blizzard） | 电竞化与战网匹配的早期样板 |

## 2000s · MMORPG 浪潮与免费游戏 {#s-2000s}

### 技术线

| 年份 | 事件与意义 |
| --- | --- |
| 2000 | 《万王之王》在华语市场上线（存疑：公测月份），华文 MMORPG 浪潮的先声 |
| 2001–2005 | 《传奇》《大话西游》《梦幻西游》等推动中国网游产业成型：点卡计费、多台服务器分区、跨服战场陆续出现——服务器架构与商业模型互相塑造 |
| 2002 | Xbox Live 上线：主机联网服务把账号、匹配、好友与商店做成标准件 |
| 2004 | **魔兽世界**（Blizzard）以「分区 + 副本实例」承接百万级在线：副本实例化让同区玩家互不挤占，成为此后 MMORPG 的架构标配（容量规划见[压测与容量规划](/19-capacity-scaling/)） |
| 2006 | AWS EC2 上线：游戏后端第一次可以按需买算力，弹性扩缩从机房工程变成云上工程 |
| 2000s 后期 | 免费游戏 + 道具计费在东亚成熟并全球化：充值流水、掉率、库存与审计把「数据运营」推到服务端核心位置（见[第 12 讲](/24-game-types-architecture/12-data-analytics)） |
| 2009 | 社交游戏平台化（Facebook 开放平台后的 Zynga 等）：高频埋点与海量玩家数据让 BI 系统成为游戏公司的标配部门 |

### 引擎线

| 年份 | 事件与意义 |
| --- | --- |
| 2004 | Half-Life 2 与 Source 引擎（Valve）；Far Cry 与 CryEngine（Crytek） |
| 2004–2006 | Unreal Engine 3 铺开，主机世代的高清化由引擎授权推动 |
| 2005 | Unity 发布（2004 年成立）：引擎降低门槛，「小团队做游戏」成为可能——移动浪潮的隐形地基 |
| 2008 | Unity 支持 iOS：App Store 生态与引擎普及互相成就，手游爆发只差时间 |

### 名作线

| 年份 | 作品 · 平台 | 它带来了什么 |
| --- | --- | --- |
| 2000 | 模拟人生 · PC（Maxis） | 生活模拟的大众市场 |
| 2001 | 光环：战斗进化 · Xbox（Bungie） | 主机 FPS 的手柄范式与双人分屏 |
| 2004 | 魔兽世界 · PC | MMORPG 的大众化顶点，「游戏即服务」的教科书 |
| 2004 | 半衰期 2 · PC（Valve） | 物理引擎与叙事演出树立 PC 技术标杆 |
| 2007 | 使命召唤 4：现代战争 · 多平台（Infinity Ward） | 现代战争设定 + 成长解锁的多人长期留存设计 |
| 2009 | Minecraft · PC（Mojang，独立团队） | 沙盒建造 + 社区生态；独立游戏改变产业叙事的标志 |

## 2010s · 移动化、长线运营与实时竞技 {#s-2010s}

### 技术线

| 年份 | 事件与意义 |
| --- | --- |
| 2009–2012 | 英雄联盟带火 Elo/MMR 匹配的大众化讨论：匹配质量成为竞技游戏的留存命脉，匹配服务从「能排到」演进为「排得公平」（匹配服务见知识库 13/15 章展开） |
| 2010 | OnLive 上线：云游戏第一次商业化尝试（2012 年重组，为后来者留下带宽与延迟的工程账本——存疑：破产/重组细节表述不一） |
| 2012 前后 | Google 开发 QUIC 协议（IETF 标准化在 2021）：弱网下更稳的传输选择，间接影响移动游戏接入层设计 |
| 2015 前后 | KCP 快速可靠协议开源（存疑：最初发布年份），移动实时对战在 UDP 上自建可靠层的做法普及 |
| 2016 | Pokémon GO（Niantic）：LBS + 海量并发的位置服务，服务端为全球玩家做地理态世界状态 |
| 2017 | 绝地求生把 100 人同步推上大众舞台：大地图 AoI、tickrate 与反作弊成为全民话题；同年堡垒之夜以「大逃杀 + 长线赛季」定义 GaaS 内容管线 |
| 2018 | GDPR 生效：全球玩家数据的合规框架收紧，账号、埋点与存档设计都要回答「数据在哪、谁能用」 |

| 2010s | 寒霜引擎在 EA 内部全线化（战地、FIFA 系），「自研引擎服务自家产品线」的样本；同时中型团队大规模转向 Unity/UE，自研引擎退守头部大厂 |

## 2020s · 云原生、跨平台与自研重估 {#s-2020s}

| 年份 | 事件与意义 |

## 三条线交汇出的今天

把三条线叠在一起看，今天的格局大致是：

- **技术线**上，网游同步从 QuakeWorld 的预测插值，长成从接入、房间、到大世界的完整分层；MMO 服务器从 UO 的分片，演进到分区、副本、跨服与云上弹性；匹配、排行、社交等通用能力沉淀为标准服务。这条线的展开就是本站[教程](/24-game-types-architecture/01-entry)与[知识库](/00-reading-guide/)的主线。
- **引擎线**上，商业引擎（Unreal、Unity、Godot 等开源新势力）与头部自研并行；引擎与客户端的分工、约束与协作边界，见[第 03 讲](/24-game-types-architecture/03-frontend-engines)。
- **名作线**上，长线运营成为主流产品形态：版本管线、数据分析、运营安全不再是「上线后的事」，而是立项就要画进图纸的部分——对应[数据分析](/24-game-types-architecture/12-data-analytics)与[版本发布](/24-game-types-architecture/17-versioning-release)两讲。

> 历史不会重复，但会押韵：每当平台（街机→主机→PC→网页→移动→云）与网络条件变化，同步模型与服务器架构都会被重新回答一遍。读历史，是为了在新约束出现时认出那些老问题。
