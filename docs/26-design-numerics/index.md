# 20. 策划与数值体系

数值是玩法的量化语言：成长感、战斗节奏、经济循环、掉落惊喜、难度曲线，全都是数值在说话。这一章从设计视角展开策划与数值的体系——工作口径、战斗数值与公式族选型、成长曲线模型、经济循环、掉落与概率、商业化数值结构、关卡难度与新手节奏，最后给出真实可查的书单与资料。

本章与教程 02《数值与经济系统》互为表里：教程 02 讲「服务端怎么把数值算对」（属性管线、确定性随机、保底状态机、货币流水），本章讲「设计侧怎么把数值定对、验对、讲清楚」。两边共用同一套术语，建议对照阅读。

> 注：本章所有涉及商业化定价、投放节奏的具体数字均为**示例模型，非行业标准**；公式与方法为公开的通用做法。
