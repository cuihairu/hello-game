# 掉落与概率设计

掉落与抽奖把随机性放进玩家的收益曲线：期望（平均值）决定性价比，方差（波动）决定情绪。[教程 02](/24-game-types-architecture/02-game-design)第 4/5 节讲实现（随机源、保底状态机、权重轮盘、分池）；本页讲设计侧——期望怎么算、保底怎么定、方差怎么调，全部数字可复算。

## 期望：性价比的唯一客观口径

期望掉落 = Σ(每种结果 × 其概率)。例：单抽 2% 出目标道具，无保底时期望抽数 = 1/0.02 = **50 抽**——这是玩家与评测者都会算的账，任何「性价比」宣传都跑不出它。多层随机（先判品质再判条目）要逐层展开成联合概率再算期望，避免「每层都看着不亏、合起来亏一半」。

## 硬保底：截断尾部，期望前移

硬保底（第 N 抽必出）改变概率分布而不改变单抽概率。算一笔可复算的账：单抽概率 p=2%，硬保底 50 抽。设 q=0.98，前 49 抽全空的概率 q^49 ≈ **37.2%**；期望抽数 = Σ(前 49 抽内命中的加权) + 50×37.2% ≈ 13.0 + 18.6 = **约 31.6 抽**。对比无保底的 50 抽：保底把长尾砍掉，期望从 50 前移到 31.6——**保底越短，期望越靠近保底数与无保底期望之间偏向保底的一侧**。设计保底时先算期望再定数：保底数与无保底期望离得越远，实际赠送的期望补贴越大。

## 软保底：递增概率的平滑版

软保底（连续未中后逐步抬升概率，如从第 30 抽起每抽 +2%）比硬保底平滑——没有「49 抽全空、第 50 抽白给」的浪费感，但期望是累积概率的级数，没有闭式速算，验收时用脚本模拟（万次抽样取均值，误差即可控）。软硬结合是常见形态：软保底管体感（越抽越接近）、硬保底管上限（保证最坏情况有底）。**两种保底的状态机实现都在教程 02 第 4.3 节。**

## 方差：惊喜与公平的旋钮

同一期望可以有完全不同的分布形态，选型按玩法目标：

- **低方差**（保底短、概率递增强）：追求「投入可预期」，适合养成类资源投放
- **高方差**（小概率大奖励）：追求「传奇时刻」，适合抽奖与稀有掉落——但必须用保底兜底最坏情况
- **伪随机分布**（连续未中概率上升、命中后回落，Dota 式）：把「连环不中」的极端体验压平，竞技玩法的体感优化器（实现与种子管理见教程 02 第 3.3/4.2 节）

掉落池设计还有一条纪律：**分池防稀释**（教程 02 第 5.3 节）——把不同价值的道具放进同一个大池子，等价于把稀有奖励的概率稀释掉；按价值分层设池，每层各自的期望单独公示。

## 公示与合规是设计输入，不是事后补丁

概率公示（抽取类玩法的概率、保底规则公开）在多数平台已是强制要求（合规红线总览见[第 17 章](/20-security-compliance/)）。设计侧的含义：**公示的概率就是玩家会拿来做决策的概率**——公示口径必须与实现严格一致（对照教程 02 第 4.4/4.5 节的审计与法律要求），「公示 2%、实际 1.5%」在合规之外更是信任层面的自毁。保底规则、总期望、池子构成，都应在设计文档阶段就按「将被公开」的标准来写。

## 常见误区

- **只算单抽概率不算总期望**：玩家算的是「拿到要多少钱/多少抽」，设计也要按这个口径算
- **保底数拍脑袋**：先定「50 抽保底」再倒推概率，期望补贴失控——顺序应该反过来
- **高方差无兜底**：最坏情况没有底，舆情会在某位「零氪非洲人」身上引爆
- **池子越合越大**：大池子稀释核心奖励的价值感，玩家「抽到的东西越来越不值钱」
- **公示口径与实现口径两套账**：审计抓出来是事故，玩家算出来是信任危机
