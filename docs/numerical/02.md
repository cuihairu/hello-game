# 战斗数值与伤害公式族

## Category

numerical 树。节点定位：伤害公式族的防御收益形状、暴击期望、TTK 验收与选型三问——设计侧与教程实现侧同公式对照。

## Definition


伤害公式是战斗数值的骨架。[教程 02](/24-game-types-architecture/02-game-design)第 3 节从服务端实现角度讲了四种主流模型与实现要点；本页从设计角度回答另一半问题：每种公式族的防御收益形状是什么、怎么选、选完怎么用战斗节奏（TTK）验收。两边公式一致，本页数字均可复算。

## Problem

公式选错族，后面全盘返工：防御收益形状决定「堆防御值不值」的玩家直觉，TTK 决定战斗节奏的手感验收。只背公式不问形状、不按 TTK 验收，数值案在评审阶段就注定返工。


### 公式族与防御收益形状

三种基础族，减伤率与有效生命（EHP）的形状决定手感：

- **减法族**：伤害 = 攻击 − 防御×k（保底 1）。防御收益线性，存在「防御无用区」（攻击远大于防御）与「防御无敌区」（防御逼近攻击×2k）——适合数值区间可控的休闲玩法
- **除法族**：伤害 = 攻击 × K/(K+防御)，减伤率 = 防御/(防御+K)。防御收益递减但**有效生命严格线性**：EHP = HP×(1+防御/K)，防御每加一个 K，有效生命翻一倍——卡牌与多数 ARPG 的默认选择
- **乘区族**：多个减伤来源各自算百分比再相乘（0.8×0.7=56% 承伤）。天然防「减伤率超 100%」， MMO 与多 buff 体系的标准做法（合并规则见教程 02 第 2 节加乘区）

除法族的线性 EHP 是它流行的根本原因：**每一点防御的价值恒定且可预告**，配装与养成收益都好解释。例：K=600，HP=1000——防御 0 时 EHP 1000；防御 600 时 EHP 2000；防御 1200 时 EHP 3000。

### 暴击与期望伤害

暴击参数（暴击率 c、暴击倍率 m）对期望伤害的贡献是线性的：期望 = 攻击 × (1 − c + c×m)。例：攻击 100、暴击率 20%、暴击倍率 150%：期望 = 100 × (0.8 + 0.2×1.5) = 110。**期望稳定、方差可控**是它对 PVP 的价值——方差大小决定「运气含量」，竞技玩法要压方差（低暴击率或保底式随机），养成玩法可以放大方差制造惊喜。

### 战斗节奏：TTK 是第一验收指标

公式选完，第一个要算的不是伤害而是**TTK（Time to Kill，有效击杀时长）**：目标 EHP ÷ 实际 DPS。它是玩家体感最直接的战斗指标——动作游戏的精英怪通常落在数秒到十余秒，卡牌单回合爆发与整局时长则另成体系。TTK 验收要做三条曲线：**开局配装**（玩家最弱时的 TTK 上限，防止劝退）、**毕业配装**（最强时的 TTK 下限，防止内容秒穿）、**版本膨胀**（两个版本间的 DPS 增幅对比，控制数值膨胀速度）。

膨胀控制的两个杠杆：**横向膨胀**（新内容复杂度、机制深度提升，数值不动）与**纵向膨胀**（数值本身上涨，旧内容贬值为「日常」）。纵向膨胀必须有明确的版本纪律（每版本涨幅上限），否则追赶成本会杀死新玩家留存——这是多数长线运营游戏的头号数值风险。

### 公式族选型的三个问题

1. **数值区间多宽**：区间可控选减法族（最直观），区间不可控选除法族（收益恒定不崩坏）
2. **要不要多来源叠加**：有多来源 buff/装备减伤，直接上乘区族，避免加法合并的饱和问题
3. **PVP 还是 PVE 为主**：PVP 压方差、盯 TTK 区间；PVE 更多用方差与机制制造「传奇一击」的记忆点

### 常见误区

- **先定伤害后定时长**：「这个技能打多少伤害」是结果，「这一仗希望打多久」才是设计
- **只算期望不算分布**：期望 110 的技能，实际每击可能是 80 也可能是 150——分布形状决定手感与公平性
- **防御参数 K 拍脑袋**：K 决定「防御饱和点」，应从目标配装的防御区间反推，并写进公式文档
- **膨胀无纪律**：每个新版本都在加系数，一年后老内容形同虚设、新玩家追不上
- **忽视保底交互**：暴击、命中、格挡等多层随机叠加后，最坏情况的体验（连不中）要用伪随机或保底兜住（对照教程 02 第 4 节与本章 05 页）
