# Gameplay Classification: The Full Genre Spectrum

## Category

industry / genres subtree. Node positioning: a collected taxonomy of gameplay categories gathered from public sources — the complete genre spectrum used by the market, with subgenre breakdowns and cross-genre hybrids.

## Definition

A video game genre is an informal classification based on how the game is *played*, not its visual or narrative elements. The same genre label applies regardless of setting: a first-person shooter stays a first-person shooter in science fiction, western, fantasy, or military dress, as long as it features a first-person camera and ranged-weapon gameplay. Genres are subjective to interpretation and often overlap; a single game can be classified into several genres simultaneously, most notably browser and mobile games.

This page collects the market-common genre spectrum into one view. It is a **taxonomy, not an architecture answer** — per the genre subtree's rule (06), genre labels serve as a communication index and problem index, never as a substitute for a design. For the architecture-side problem models, see [models/01](/industry/models/01) (six-question typology).

## Classification Schemes

Genres can be classified along several independent axes. Only gameplay is a true genre axis; the others are alternative categorization schemes:

| Axis | Meaning | Examples |
| --- | --- | --- |
| Gameplay (true genre) | How the game is played | shooter, platformer, RPG, strategy |
| Platform | What hardware it runs on | mobile, console, PC, browser |
| Mode | Single-player vs. multiplayer | SP, MP, co-op, PvP, PvE, MMO |
| Narrative | Setting/story style (not a genre) | sci-fi, fantasy, horror |
| Production | Budget/provenance | AAA, indie, doujin, fan game |
| Design | Structural design labels | casual, hypercasual, gacha, open world |

The gameplay axis is the only one the genre subtree treats as primary. The others are context for scoping a project, not genre decisions.

## The Genre Spectrum

The spectrum below follows the commonly used genre families. Each family lists its major subgenres; cross-genre hybrids are noted where they are market-common.

### Action

The broadest family, defined by physical challenges — reflexes, timing, and spatial coordination.

| Subgenre | Core trait |
| --- | --- |
| Arcade | Simple rules, score-chasing, short sessions |
| Platformer | Jumping between platforms; precision movement |
| Fighting | One-on-one melee, combos, frame data |
| Beat 'em up | Side-scrolling melee against crowds |
| Hack and slash | Melee combat with loot progression |
| Shooter | Ranged weaponry, aim-centric |
| ─ First-person (FPS) | Camera mimics protagonist's eyes |
| ─ Third-person (TPS) | Camera behind the character |
| ─ Hero shooter | Team-based, character abilities |
| ─ Arena shooter | Fast movement, arena combat |
| ─ Tactical shooter | Slow, position-oriented, one-shot lethality |
| ─ Extraction shooter | Loot-and-extract runs with PvPvE |
| ─ Shoot 'em up | Bullet-pattern dodging |
| ─ Bullet hell | Dense bullet patterns, tiny hitbox |
| ─ Rail shooter | Camera on rails, shooting gallery |
| ─ Twin-stick | Dual analog sticks, top-down |
| ─ Light gun | Aim with a peripheral |
| ─ Looter shooter | Shooter + loot rarity |
| Survival | Resource scarcity, managing threats |
| ─ Battle royale | Last-one-standing, shrinking zone |

### Action-Adventure

Hybrid of action and adventure — physical challenges plus exploration and puzzle-solving.

| Subgenre | Core trait |
| --- | --- |
| Metroidvania | Connected map, power-ups gate progress |
| Stealth | Avoiding detection over combat |
| Survival horror | Scarcity + horror atmosphere |
| GTA clone (open-world action) | Open city, driving + shooting + story |

### Adventure

Exploration, narrative, and puzzle-solving over combat.

| Subgenre | Core trait |
| --- | --- |
| Graphic adventure | Point-and-click, inventory puzzles |
| Interactive fiction | Text-driven, parser or choice-based |
| Visual novel | Narrative-dominant, dialogue choices |
| Walking simulator | Atmospheric exploration, minimal interaction |
| Escape room | Confined-space puzzles, timed |
| Interactive film | FMV branching narrative |

### Digital Tabletop

Digitized board/card games.

| Subgenre | Core trait |
| --- | --- |
| Deck-building | Cards added to deck during play |
| ─ Roguelike deck-building | Deck-building + run-based roguelike structure |
| Digital collectible card | Persistent card collection, constructed decks |

### Puzzle

Logic and pattern-solving.

| Subgenre | Core trait |
| --- | --- |
| Tile-matching | Swap/clear matching tiles |
| Hidden object | Find items in a scene |
| Sokoban-like | Block-pushing logic |
| Falling-sand | Physics-based sand simulation |

### Role-Playing (RPG)

Character growth and storytelling as the core.

| Subgenre | Core trait |
| --- | --- |
| Action RPG | Real-time combat + stats |
| ─ Soulslike | High difficulty, deliberate combat |
| Turn-based RPG | Menu-driven, turn order |
| Tactical RPG | Grid-based positioning + turns |
| Dungeon crawl | Procedural dungeons, loot |
| Roguelike | Permadeath, procedural, grid-based (see 09) |
| MMORPG | Persistent shared world, many players |
| Monster-taming | Capture and train creatures |
| MUD | Text-based multiplayer RPG |

### Simulation

Modeling real-world systems.

| Subgenre | Core trait |
| --- | --- |
| Construction & management (CMS) | Build and run an enterprise |
| ─ City-building | Urban planning |
| ─ Business | Company management |
| ─ Government | Political simulation |
| Life simulation | Daily life, relationships |
| ─ Dating sim | Romance choices |
| ─ Farm life | Agriculture |
| ─ God game | Indirect influence over a world |
| ─ Social sim | Community interactions |
| ─ Virtual pet | Care for a creature |
| Vehicle simulation | Operating vehicles |
| ─ Flight / combat flight | Aircraft |
| ─ Racing / sim racing | Cars |

| ─ Submarine | Submarines |

### Sports

Athletic competition.

| Subgenre | Core trait |
| --- | --- |
| Team sports | Football, basketball, etc. |
| Racing | Lap-based speed comparison |
| ─ Kart racing | Arcade, items |
| Fishing | Angling simulation |

### Strategy

Planning and resource management.

| Subgenre | Core trait |
| --- | --- |
| Real-time (RTS/RTT) | Live command and control |
| ─ MOBA | 5v5 hero battle, lanes |
| ─ Auto battler | Draft + auto-combat |

## Cross-Genre and Hybrid Reality

Most real products are hybrids. The market-common hybrids that matter for architecture:

- **Roguelike deck-building** (Slay the Spire): deck-building + run structure — one of the most commercially influential hybrids of the 2010s.
- **Looter shooter** (Destiny, Borderlands): shooter + loot rarity.
- **Survival crafting** (Minecraft, Valheim): gathering + building + shared world.
- **Gacha RPG**: RPG + gacha monetization (see 08).
- **Battle royale**: shooter + last-standing survival.

The genre table in [genre-coverage](/system/genre-coverage.md) maps 21 market-common genres to the feature components each asks for first — that is the architecture-side companion to this taxonomy.

## Problem

A taxonomy without discipline becomes an excuse to skip analysis. Two pitfalls dominate:

- **Genre = architecture answer.** A "MMO" or "SLG" label is not a design. The shape of the system is decided by state sharing, time advance, content production, operational rhythm, and commercial constraints — two projects both called MMO can be technically worlds apart.
- **Theme vs. genre confusion.** Theme (cultivation, wuxia, Three Kingdoms, anime-style) is a reskin, not a piece change. Only gameplay and business form change the server component requirements.
