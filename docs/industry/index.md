# Industry and Methodology

## Category

Overview of the industry tree. Node positioning: first answer "what is a project in the game industry" and only then talk technology — the methodology subtree supplies the analytical method, the problem models subtree supplies the technical shape of each type, the type spotlights provide a quick-reference entry, the platforms subtree handles the engineering of external constraints, and the career map, a horizontal node, answers how roles and people are staffed.

## Definition

The engineering reality of a game project is jointly determined by three inputs: gameplay type (which decides the dominant contradiction), platform (which decides the technical boundary), and business model (which decides the version and operations cadence). The industry tree unfolds these three inputs into four subtrees: methodology supplies the analytical framework, problem models give six comparable technical shapes, type spotlights serve as a quick index, and the platforms subtree handles how the outside world shapes the system in reverse; on top of that, a horizontal career map node — the three inputs are ultimately executed by people, and the four job families' staffing, growth, and mobility answer "who builds the project."
