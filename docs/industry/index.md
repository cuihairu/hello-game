# 行业与方法论

## Category

industry 树总览。节点定位：先回答「游戏行业里的项目是什么」再谈技术——方法论子树给分析方法，问题模型子树给类型的技术形态，类型专题给速览入口，平台子树给外部约束的工程化。

## Definition

游戏项目的工程现实由三个输入共同决定：玩法类型（决定主导矛盾）、平台（决定技术边界）、商业形态（决定版本与运营节奏）。industry 树把这三个输入展开成四棵子树：方法论给分析框架，问题模型给六种可对照的技术形态，类型专题做快速索引，平台子树处理外部世界的反向塑造。
