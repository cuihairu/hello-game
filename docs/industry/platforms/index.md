# 平台生态、渠道与 SDK

## Category

industry / platforms 子树总览。覆盖：平台与渠道生态（01）、小游戏平台约束（02）、四类 SDK（03）、发布版本与商业模式（04）。

## Definition

这一章解释平台生态为何会深刻改变项目技术形态。渠道、小游戏平台、登录支付、广告和社交 SDK 不只是接入工作，而是分发与商业模式的一部分。

这一章读完以后，应该能把下面几件事说清楚：

- 能理解平台能力如何反向塑造产品和技术方案
- 能判断 SDK 集成应如何隔离风险
- 能管理平台版本和商业模式的耦合
