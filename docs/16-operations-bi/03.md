# 经济、平衡与风控分析

经济分析、数值平衡和风控分析经常分别归属不同岗位：策划看平衡，运营看收入，安全团队看异常。可是在长线项目里，这三者其实都在追踪同一个系统的不同侧面，也就是资源和行为是否仍然处在可控区间内。

## 为什么这三类分析不能分家

只要玩家行为会影响资源分布、成长速度和社交竞争，这三类分析就天然耦合：

- 经济异常可能来自数值投放失控，也可能来自作弊或黑产
- 付费结构波动可能来自活动设计，也可能来自洗号、退款套利或代充
- 某个玩法参与率下降，可能是平衡问题，也可能是奖励结构出了偏差

如果团队把这些分析完全切开，就会反复出现“每个人都看到局部异常，但没人能解释整体变化”的情况。

## 经济分析看的不是总量，而是流向

只看总收入、总消耗、总持有量，通常不够。经济分析更有价值的问题包括：

- 哪类资源正在持续通胀或通缩
- 高价值用户和普通用户的资源结构差异是否被拉大
- 某个活动或礼包是否改变了关键货币的产消平衡
- 稀缺道具是否开始向少数账户异常集中

也就是说，经济分析关心的不是表面数字好不好看，而是资源分布是否偏离了产品预期。

## 平衡分析不能只靠主观体验

很多项目做数值平衡时，容易把讨论停留在“感觉太肝”“感觉太难”“感觉数值崩了”。这些判断当然重要，但如果没有行为数据支撑，调整会很容易变成摆锤：

- 看到流失就一味加福利，结果核心挑战被掏空
- 看到付费下降就加促销，结果价格锚点被打坏
- 看到高端玩家抱怨就拉高上限，结果中低层用户被进一步甩开

更有效的平衡分析，通常会同时看：

- 分层通过率和失败率
- 关键养成线的完成时间
- 核心玩法的参与深度和放弃节点
- 不同付费层级的成长效率差异

这样做的目的是把“体验判断”落到可观测事实上，而不是用情绪互相覆盖。

## 风控分析为什么不能只盯作弊率

风控分析不仅是抓外挂，还要看异常行为如何改变经济和经营数据。例如：

- 刷资源脚本会放大货币通胀，拖垮商业化和排行榜公信力
- 工作室批量起号会污染新增、留存和召回数据
- 退款套利和代充会制造虚假收入峰值
- 群控脚本会让某些活动看起来参与率很高，实际上没有真实价值

所以风控分析应该和经济分析共享数据基础，例如资产流水、订单流水、登录行为、设备指纹、社交传播链。否则风控只能看到“可疑”，看不到“影响了什么”。

## 更实用的分析结构

一个更有效的做法，是把这三类分析都放到“事实 -> 偏离 -> 原因 -> 动作”的框架里：

- 事实：哪些关键指标发生了异常变化
- 偏离：与历史、同层用户、实验组或目标区间相比偏在哪里
- 原因：是版本调整、活动投放、经济结构变化还是异常行为导致
- 动作：该调数值、调投放、调活动、加限制，还是直接进入风控处置

这样的好处是，分析结果天然能接到经营动作，而不是停留在描述现象。

## 常见错误

- 经济分析只看总量，不看分层、分区和流向
- 平衡调整只看头部反馈，不看真实行为数据
- 风控分析孤立运行，不和付费、经济、活动结果做交叉验证
- 发现异常后只有结论，没有后续动作链路和验证机制

经济、平衡与风控分析真正成熟的状态，不是报表更多，而是团队能区分“正常波动”和“结构性偏移”，并知道应该由谁、用什么手段把系统拉回可控范围。
