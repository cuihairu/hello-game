# 压测、容量规划与扩缩容

## Category

server / capacity 子树总览。覆盖：压测与容量规划（01）、扩缩容（02）、分区迁移合服（03）、多地域与平台化运维（04）。

## Definition

这组附录把容量、扩缩容、迁移和多地域架构集中展开，适合在上线准备和长线运营治理阶段查阅。

这一章读完以后，应该能把下面几件事说清楚：

- 能从压测结果推导容量模型
- 能理解扩缩容和迁移真正困难的部分
- 知道多地域架构为何会显著放大运维复杂度
