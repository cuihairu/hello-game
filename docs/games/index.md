# 知名游戏库

> [历史线](/history/)管时间，这里管**分类浏览**：按玩法类目组织代表性作品，每个条目带一个**后端技术栏**——服务器架构、同步模型、匹配服务、实时通信、存储与存档、反作弊校验、UGC 与社交服务。它既是一份游戏索引，也是一份「这些问题别人怎么解」的案例库：点条目里的技术标签，可以直接跳到站内对应的知识点。

## 玩法归类体系

| 类目 | 定义 | 入库代表作 |
| --- | --- | --- |
| FPS/TPS | 第一/第三人称射击：以实时命中判定与低延迟同步为核心 | Quake、反恐精英、守望先锋 |
| MOBA | 多人在线竞技：小队对抗 + 局内成长 + 强服务端裁决 | 英雄联盟、Dota 2、王者荣耀 |
| RTS | 即时战略：大量单位并发操控与确定性模拟 | 星际争霸 |
| MMORPG | 大型多人在线角色扮演：持久世界 + 社会系统 + 长线运营 | MUD1、魔兽世界、最终幻想 XIV、剑网 3 |
| ARPG | 动作角色扮演：实时战斗 + 装备成长 + 掉落经济 | 暗黑破坏神 III、原神、艾尔登法环 |
| 开放世界 | 大地图无缝探索与非线性目标，常与在线服务结合 | GTA Online、原神、艾尔登法环 |
| Roguelike | 程序生成 + 永久死亡 + 局内成长，多为单机形态 | 哈迪斯 |
| 沙盒 | 给工具不给目标：玩家自造玩法与内容生态 | 我的世界、Roblox |
| 派对/休闲 | 低门槛多人聚会玩法，短局高频重开 | 糖豆人 |
| 叙事 | 以故事与情感体验为核心，常含社交叙事 | 光·遇 |
| 竞速 | 载具竞速与对抗，讲究延迟补偿与排位积分 | 马里奥赛车 8 豪华版、QQ 飞车 |
| 体育 | 现实体育拟真对抗，长线卡牌化运营（UT 模式） | EA Sports FC（FIFA） |
| 卡牌构筑 | 卡组构建 + 对局策略，回合制适合全服务端权威 | 炉石传说 |
| 生存建造 | 资源采集 + 建造 + 生存压力，多见持久世界服务器 | 饥荒：联机版、我的世界 |

## 怎么读后端技术栏

- **服务器架构**回答「世界被怎么切」：分片/分区、副本实例、跨服、房间制、云实例化，对应[按问题域归纳各类游戏](/09-problem-domain/)；
- **同步模型**回答「谁相信谁」：帧同步还是状态同步、服务端权威还是客户端预言，对应[第 04 讲](/24-game-types-architecture/04-network)；
- **匹配 / 排行 / 社交**是通用游戏服务的三大件，展开见[通用游戏服务](/15-common-services/)与[缓存与中间件](/14-cache-middleware/)；
- 写「未公开」的字段是厂商没有公开资料的，不做猜测；纯单机游戏如实写「不适用」——留白本身就是分类学信息（对照[哈迪斯](#条目库)）。

条目与技术标签会随批次扩充；发现史实或技术细节错漏，欢迎开 issue 指正。
