# 设计

## Category

design 树总览。节点定位：设计侧知识按问题域组织——先给类型的技术形态（问题模型），再给横向速查（problem-domains），后续设计子域（玩法设计、关卡、社交等）按同一模式扩展。

## Definition

设计侧回答「这是个什么问题」：industry/models 子树把玩法标签译成六种技术问题模型并给分型方法；problem-domains 子树把五类问题域的关键判断压成速查页。技术树（server/system/client 等）回答「这个问题怎么解」，两层的衔接点就是归型。
