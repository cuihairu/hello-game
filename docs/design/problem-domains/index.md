# 按问题域归纳各类游戏

design / problem-domains 子树总览。覆盖：单局房间型（01）、强实时对战型（02）、持续在线世界型（03）、长周期成长型（04）、经济平台型（05）五类速查与使用说明（06）。

## Definition

这组附录按问题域重新聚类不同游戏，目的不是重复主线，而是把多章内容压缩成横向对照表。它更适合回顾和盘点，而不是第一次学习。

这一章读完以后，应该能把下面几件事说清楚：

- 快速比较不同问题域的系统重点
- 回看相似项目为什么会采用相似架构
- 为方案评审提供横向参照
