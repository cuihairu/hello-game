# Grouping Games by Problem Domain

## Category

Overview of the design / problem-domains subtree. Coverage: room-based session (01), hard-real-time competitive (02), persistent online world (03), long-cycle progression (04), and economy/platform (05) quick references, plus usage instructions (06).

## Definition

This group of appendices re-clusters games by problem domain. Its purpose is not to repeat the main line, but to compress the content of many chapters into crosswise comparison tables. It is better suited to review and inventory than to first-time study.

The core questions covered by this group of records:

- The system focus of each problem domain
- Why similar projects adopt similar architectures
- How genre cross-reference is used in solution review
