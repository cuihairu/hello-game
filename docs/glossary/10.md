# 英文术语与词源

## Category

glossary 树节点。词汇速查表定位：收录正文各篇反复出现的英文术语与品类缩写，每条给英文原词、中译、一句话口径、来源/词源与站内落点；与九个「术语约定」章互补——那边回答中文架构词（谁负责、状态放哪里、失败谁兜底），本页回答英文技术词是什么、从哪来。

## Definition

游戏开发的英文术语有三类：有可查出处的（论文、官方文档、GDC 讲稿、源码），行业通行的工程词，以及社区俚语。三类混在一起时最容易被「词源营销」带偏——把通行词说成出自某论文，把社区经验词说成学术概念。本页每条按同一个四件套收录：英文原词与中译、一句话口径（只给判断用的一句话，机制展开交给站内落点）、来源/词源（按可查性如实标注）、站内落点（交叉链接到展开该机制的篇目）。

## Problem

术语文章最常见的毛病是编造词源：把「好像听说过」写成「出自某某论文」，读者引用一次就以讹传讹。本页的口径是宁可空着不编——查得到出处的给出处（论文/官方文档/源码/GDC 讲稿），通行工程词标「通行」，确实查不到首引的标「来源未考」。出处只写「公开可查、站内已核对」的事实：评级词条与[PVP 匹配](/system/pvp-matchmaking)页的口径一致，开源件定位与[开源服务器地图](/server/map)的 commit 锚定一致。

## 收录与判定口径

首版从同步、网络、运行时、系统、数值、BI、历史线与游戏库各篇及[品类与组件覆盖对照](/system/genre-coverage)页抽取术语，按主题分四组：网络与同步、引擎与运行时、玩法与品类、数值与经济，共 74 条（含开源件 9 条；2026-10-09 随玩法系统丰富批扩充 17 条）。词条不追行业唯一标准（那九个术语章的口径在此同样适用），只保证两条：中译与站内正文一致；出处与站内已核对的源码事实一致。后续随新篇目滚动扩充。

| Rollback Netcode | 回滚网络 | 输入迟到就把模拟回退到该帧重跑 | GGPO（格斗游戏社区开发者 Tony Cannon 创建，后开源）使 rollback netcode 成为标准词，更早思想未考 | [帧同步详解](/server/sync/03) |
| Snapshot / Delta | 快照/增量 | 每 tick 留全量快照，线上传差量 | 常引 Valve 官方文档 | [同步模型](/server/sync/02) |
| Interpolation / Extrapolation | 插值/外插 | 在两个已知状态间平滑，或向前外推 | 常引 Valve 官方文档（cl_interp 口径） | [预测、补偿与纠正](/server/sync/05) |
| Reliable UDP | 可靠 UDP | 在 UDP 上自建重传与有序，避开 TCP 队头阻塞 | 工程通行词；开源实现常引 KCP（开源 ARQ 协议）与 QUIC（RFC 9000） | [传输层与接入协议选择](/networking/03) |
| Reconnection | 断线重连 | 掉线后按快照与追帧恢复到当前进度 | 通行工程词，来源未考 | [暂停、继续、追帧与断线重连](/server/sync/04) |
| NAT Traversal | NAT 穿透 | 让处于内网两侧的对端建立直连的一类手法统称 | RFC 5128（2008）系统整理 P2P 场景下的 NAT 处理手法；更早工程实践未考 | [传输层与接入协议选择](/networking/03) |
| UDP Hole Punching | UDP 打洞 | 双方同时向对方的公网映射发包，把映射「凿穿」成直连 | 手法描述见 RFC 5128；「打洞」是中文工程社区对 hole punching 的直译俗称 | [传输层与接入协议选择](/networking/03) |
| STUN / TURN | 会话穿透/中继穿越 | STUN 探测自己的公网映射，打不通时 TURN 走服务器中继 | 出处：STUN 见 RFC 5389（2008，替代 RFC 3489），TURN 见 RFC 5766（2010） | [传输层与接入协议选择](/networking/03) |
| Listen Server | 监听服务器 | 玩家主机兼任服务端的对局形态 | 1990 年代 FPS 服务器语境通行（Quake 系的 dedicated/listen 之分是常引节点），首引未考 | [开源服务器地图](/server/map) |
| Dedicated Server | 专用服务器 | 不渲染不操作、只跑模拟的独立服务端 | 同上，Quake 时代通行；词本身也是通用部署词 | [开源服务器地图](/server/map) |
| Determinism | 确定性 | 同输入序列在任何机器上得到同状态，帧同步的生命线 | 与帧同步文献同源，常引《1,500 Archers on a 28.8》（GDC 2001）；词本身是计算理论通用词 | [确定性与数值一致性](/server/sync/06) |
| Server Day | 服务器日 | 重置与结算按服务器固定时区的自然日对齐 | 工程通行口径（与玩家本地时区切割），首引未考 | [体力与次数门控](/system/stamina) |
