# 术语约定

游戏项目里，同一个词经常同时承载产品语义、工程语义和组织语义，不同岗位和不同项目各说各话是常见现象。这一部分把全书高频出现的术语拉回同一套上下文里解释。重点不是追求行业唯一标准，而是让读者能迅速判断：谁负责、状态放哪里、变更何时生效、失败后谁兜底。
