# 12. 缓存、中间件与基础设施

这一章讨论那些经常被视作“配件”的基础设施为何会决定系统上限。缓存、MQ、注册发现、对象存储和 CDN 如果定位不清，很容易从助力变成隐患。

这一章读完以后，应该能把下面几件事说清楚：

- 能判断基础设施应该承担什么，不该承担什么
- 能理解缓存一致性和中间件语义的真实成本
- 能把基础设施选型和业务链路优先级对齐
