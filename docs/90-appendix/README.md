# 附录与横向索引

附录负责横向索引和专题展开，不与主线争夺解释职责。它的目标是帮助读者在已经理解主线后，快速回看某一类问题、某一类游戏或某一条工程链路。

这一章读完以后，应该能把下面几件事说清楚：

- 能按不同维度快速回看全书内容
- 能在分享、评审和培训中快速取用索引
- 能把主线知识压缩成专题视图
