# 运营与可观测性

## Category

operation 树总览。节点定位：上线之后系统暴露的不再是设计图而是运行行为——运营子树管「让系统持续被正确驱动」，可观测性子树管「让运行行为变成可定位的证据」。两棵子树共享同一组上游（配置与发布链路）与同一套口径纪律。

## Definition

运营能力（活动、商业化、触达、风控）本质是一套持续驱动系统变化的控制面；可观测性（日志、指标、Tracing、Profiling、压测、稳定性治理）把运行行为转成可理解、可定位、可决策的信息。两者的交汇点是数据口径：运营判断靠口径对齐，故障定位靠证据链可信——口径失守，两边同时失效。
