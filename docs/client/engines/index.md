# 引擎选择、语言地图与工具生态

## Category

client / engines 子树总览。覆盖：引擎商业模式（01）、语言地图（02）、项目与团队选型（03）。

## Definition

这组附录帮助读者把引擎、语言和工具生态放回实际商业与团队背景里理解。它不是排行榜，而是选型时的背景材料。

这一章读完以后，应该能把下面几件事说清楚：

- 能把技术栈选择和项目条件关联起来
- 知道商业模式、团队结构和工具生态如何影响长期成本
- 避免只凭口碑做引擎和语言决策

## Related
