# Web Game Frontend System

## Category

Overview of the client / web subtree. Covers: Canvas 2D (01), WebGL (02), engines and Cocos (03), game UI (04), mini-game platforms (05), client internal layering (06).

## Definition

The Web is one of the lowest-cost paths to reach players: open a browser and play, with mini-game platforms building distribution and social chains in. This chapter lays out the complete Web game frontend system from a technical angle — from Canvas 2D rendering fundamentals, to WebGL and 3D rendering, to how engines and Cocos Creator work, and then on to game UI, the mini-game platform environment, and client internal layering.

This chapter and Chapter 8 "Client Architecture and Engine System" are two sides of the same coin: Chapter 8 answers "how is the client architecture decided and how are the boundaries drawn," while this chapter answers "how do you actually use and run the technologies on the Web side."
