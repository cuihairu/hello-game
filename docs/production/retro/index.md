# Selection, Practice, Retrospective, and Checklists

## Category

Overview of the production / retro subtree. Covers: selection method (01), architecture pattern comparison (02), review checklist (03), failure case analysis (04), personal self-audit (05).

## Definition

This chapter pushes the preceding material back down to the practice layer, answering "how do you choose", "how do you run a retrospective", and "how do you avoid repeating the same mistakes". It does not list best practices; it helps a team build decision and correction mechanisms.

The core questions these notes deal with:

- How to distill the judgments made earlier into selection and retrospective checklists
- Common failure modes and their triggering conditions
- How to spot unverified assumptions during a design review
